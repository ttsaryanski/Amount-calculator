# Amount Calculator - Android App

Приложение за изчисляване на ресто с поддръжка на BGN и EUR валути.

## Функционалности

- Изчисляване на ресто (разлика между платена и дължима сума)
- Поддръжка на две валути: BGN и EUR
- Автоматична конверсия между валутите
- Фиксиран курс: 1 EUR = 1.95583 BGN
- Резултатът се показва в двете валути

## Използване

1. Въведете дължимата сума и изберете валута (BGN или EUR)
2. Въведете платената сума и изберете валута (BGN или EUR)
3. Натиснете бутона "Изчисли" или някой от операторните бутони
4. Резултатът ще се покаже в двете валути

## Технически детайли

- Минимална Android версия: API 24 (Android 7.0)
- Target SDK: API 34
- Език: Java
- UI Framework: Android Views

## Building

Използвайте Android Studio или Gradle:

```bash
./gradlew assembleDebug
```

APK файлът ще откриете в `app/build/outputs/apk/debug/`
